# Sistema di Gestione delle Spese Personali e del Budget
**Esame di Fondamenti di Informatica**

Questo progetto consiste in un'applicazione console sviluppata in Python per la gestione delle finanze personali, con persistenza dei dati su database relazionale SQLite.

## 🚀 Requisiti per l’esecuzione
Per eseguire correttamente il programma, assicurarsi di avere installato:
- **Interprete:** Python 3.x
- **Database:** SQLite3 (libreria standard inclusa in Python)
- **Librerie standard utilizzate:** `sqlite3`, `datetime`, `os`
